# PPDD code 🧑🏻‍💻💬👩🏾‍💻
Code used to compile the Pair-Programming Dialogue Dataset (PPDD).
Dataset available separately at ([Open University data repository](https://doi.org/10.21954/ou.rd.30994039)).

Research work by Cecilia Domingo, Paul Piwek, Svetlana Stoyanchev, and Michel Wermelinger with financial support from EPSRC Training Grant DTP 2020-2021 Open University and Toshiba Europe Limited.
